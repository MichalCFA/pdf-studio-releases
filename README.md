# PDF Studio dla Windows

[Pobierz najnowszy instalator](https://github.com/MichalCFA/pdf-studio-releases/releases/latest)

Wybierz plik kończący się na `windows-x64-setup.exe`. Konto GitHub nie jest potrzebne. Po instalacji PDF Studio sprawdza kolejne podpisane aktualizacje automatycznie. Dokumenty PDF są przetwarzane lokalnie.

[Listę zmian znajdziesz przy każdym wydaniu](https://github.com/MichalCFA/pdf-studio-releases/releases).
